# Going back to the previous site

The site as it was before the redesign of 21 November 2026 is kept in this repository under the tag
`previous-site-2026-11-21`. Nothing was deleted from its history.

To put it back, from a copy of this repository:

    git checkout previous-site-2026-11-21 -- .
    git commit -m "Back to the previous site"
    git push
